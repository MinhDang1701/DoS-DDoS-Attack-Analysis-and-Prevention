# Figure 4.8. The AI-Driven Defense Cycle (Future-Extension Direction, Not Experimentally Implemented)

```
                     ┌─────────────────────┐
                     │   Collect Traffic      │
                     └──────────┬──────────┘
                                    │
                     ┌──────────▼──────────┐
                     │  Continue Monitoring   │◀────────────────────┐
                     └──────────┬──────────┘                       │
                                    │                                       │
                     ┌──────────▼──────────┐                       │
                     │   Analyze Behavior     │                       │
                     └──────────┬──────────┘                       │
                                    │                                       │
                     ┌──────────▼──────────┐                       │
                     │   Detect Anomalies      │                       │
                     └──────────┬──────────┘                       │
                                    │                                       │
                     ┌──────────▼──────────┐                       │
                     │   Assess Severity        │                       │
                     └──────────┬──────────┘                       │
                                    │                                       │
                     ┌──────────▼──────────┐                       │
                     │  Respond / Recommend   │───────────────────────┘
                     │  Measures                  │
                     └─────────────────────┘
```

This diagram depicts the AI-driven Defense cycle described in Section 4.4.2 of the report as a closed feedback loop: continuously collecting traffic, analyzing behavior, detecting anomalies, assessing severity, responding with or recommending mitigation measures, and returning to ongoing monitoring. This cycle represents a future-extension direction for the project and was not implemented as an automated system in the current experimental work.
